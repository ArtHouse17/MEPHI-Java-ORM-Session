# Hibernate Academy

Учебный проект по ORM и Hibernate. Через API преподаватель добавляет уроки, задания и тесты, а студент записывается на курс и сдаёт работы.

У пользователя один профиль. В курсе может быть несколько модулей, а один тег можно добавить к разным курсам.

Используются Java 21, Spring Boot, Hibernate, PostgreSQL, Liquibase и Maven.

## Запуск

Скопируй `.env.example` в `.env` и задай `DB_PASSWORD`. Из корня проекта запусти Docker Compose.

```sh
docker compose up --build -d
```

Демонстрационные данные загружаются при запуске приложения. Чтобы проверить, что оно работает, открой [список курсов](http://localhost:8080/api/courses).

В файле [demo.http](demo.http) есть примеры запросов для IntelliJ IDEA. Если выполнить их по порядку на свежей базе, можно сдать и оценить задание, пройти тест и посмотреть результат. В запросах от имени студента или преподавателя укажи его ID в заголовке `X-Actor-Id`.

## Тесты

```sh
mvn -Pquality clean verify
```
